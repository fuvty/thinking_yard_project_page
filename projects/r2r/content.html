The Discovery

Not all tokens are equal.

In the 7.6M-token routing training set, R1-1.5B and R1-32B agree on most next-token predictions under the same context. Only about 5% of tokens are labeled path-divergent.

89%
Identical Tokens
Both models predict the same next token under the same context, so the small model’s output can be used.
6%
Neutral Differences
Minor variations like "let's" vs "let us" that don't affect reasoning outcomes.
5%
Divergent Tokens
Differences that change the reasoning path. The router learns to identify these tokens for correction by the LLM.
Learn more about token classification

Identical tokens occur when both the small and large language model predict the exact same next token given the same context. Since they agree, we can safely use the faster small model.

Neutral differences are different predictions whose sentence-level continuations remain equivalent in meaning, such as abbreviations or stylistic variations.

Divergent tokens genuinely alter the meaning, logic, or conclusion of the current sentence, thus diverging the subsequent reasoning path. These are the critical tokens where we need the large model's guidance.

How It Works

Intelligent token routing.

R2R uses a lightweight neural router trained on automatically generated token-level labels to decide which tokens need the large model's attention.

Automatic Data Generation Pipeline

A key contribution of R2R is an automatic pipeline for generating token-level routing labels without expensive human annotation:

  1. LLM generates the reference response.
  2. SLM prefills that response to find differing next-token predictions.
  3. LLM continues each differing SLM token to the sentence boundary; the reference continuation comes from the original response.
  4. Verifier model compares the sentence continuations to label neutral or divergent differences.

This pipeline produces large-scale training data automatically, enabling the router to learn which token differences actually matter for reasoning.

Path-Following Routing Strategy

When generating routing labels, we compare the next-token predictions of the SLM and LLM. Identical predictions can use the SLM output. For differing predictions, continuation and verification determine whether the difference is:

  • Neutral: Doesn't affect reasoning outcomes (use SLM)
  • Divergent: Alters the reasoning path (route to LLM)

Sentence-level verification provides offline training labels. During inference, the neural router predicts divergence from SLM features and invokes the LLM when its score exceeds a threshold. It approximates the labeling strategy rather than verifying every continuation.

Neural Router Architecture

The router is a lightweight 56M-parameter feed-forward network that takes three inputs from the SLM:

  • Top-100 SLM logits: Captures prediction uncertainty (higher entropy indicates potential divergence)
  • Token embeddings: Encodes token frequency biases (rare tokens are more likely to diverge)
  • Last-layer hidden states: Provides semantic context for the current generation step

A divergence score enables immediate routing decisions. Adjusting the threshold changes LLM usage without retraining; the reported configuration uses the LLM for 11–15% of tokens.

Predictive Indicators of Divergence

SLM Entropy

Average SLM output entropy is 3.8× as high for divergent tokens as for non-divergent tokens, indicating greater prediction uncertainty.

Token Frequency

Low-frequency tokens are more likely to be divergent in the training data, suggesting token rarity is a useful predictive signal.

R2R naturally learns efficient routing patterns: fewer LLM calls during straightforward reply phases, and more at the beginning and end of each thought where reasoning direction is determined.
